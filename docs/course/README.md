# Course journey

Work in one clone throughout the course. Follow [setup](../setup.md), then use the terminal commands and Python API in each lesson. The [four notebooks](../../notebooks/README.md) offer the same project as an optional exploration space. Reuse your runs, decisions and outputs between activities; there is nothing to submit. Checkpoints help you check your own understanding.
