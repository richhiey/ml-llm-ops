# Actual authored Sprint 2 evidence

These are observations from seven real CPU runs on Fashion-MNIST: baseline, five distinct one-factor candidates and a baseline autologging repeat. The reference source includes the authored Sprint 1 partner intake extension (threshold 24); all seven runs share its source, dataset, split, environment and initial weight identities. Students retain their own completed source and produce their own run IDs.

`comparison.json` records full-precision metrics and controls. Each named folder retains configuration, history, metrics and the raw 3,000-row validation prediction CSV. They are reference observations, not preloaded MLflow records or guaranteed outputs on every computer. Original learned weights and recipe/source archives remain in the author's actual MLflow store and are verified by private author evidence; learners generate those artifacts locally.

The assistant request and response are an actual authoring demonstration using Codex. They are not a student submission, classroom approval record or automated promotion decision. Validate each claim against the raw records before using it. The official test split was not used in this study.
