# Module A · From model to reliable pipeline

Linden Facilities needs 24 hourly energy-demand estimates in one complete file within 60 seconds. You will build an understandable pipeline and hand over a result another person can rebuild.

**Start:** [Set up locally](docs/setup.md), then open the current sprint below. You need ML fundamentals and basic Python. No API key or GPU is needed.

| 2 | [Track and compare experiments](notebooks/02-tracking-and-evidence.ipynb) · [Colab](https://colab.research.google.com/github/richhiey/ml-llm-ops/blob/main/module-a/notebooks/02-tracking-and-evidence.ipynb) | Plan five controlled runs, inspect MLflow and check recommendations. |

## How to work

Use **four notebooks in total**. Each contains explained code, prediction prompts, independent practice and its sprint checkpoint. Keep your answers there and carry the same editable project forward. Campus pages are short companion notes; you do not rerun the whole notebook for each page or submit a new report for every activity.

[Browse the Campus notes](lessons/README.md) when you need an explanation or practice brief. [Technical reference](docs/README.md) is available for lookup. [Maintainer tools and verification](maintainer/README.md) support course authors.
