# Four local Campus notebooks

Use the [repository setup](https://github.com/richhiey/ml-llm-ops/blob/main/docs/setup.md) and select the project's Python 3.12 kernel. Run each notebook's sections in order. The notebooks import the same core pipeline, tracking, lifecycle, evidence and visualization modules used by the cumulative project.

1. [Pipeline and extension](https://github.com/richhiey/ml-llm-ops/blob/main/notebooks/01-pipeline-and-extension.ipynb): trace the stages, inspect a contract plot, follow a bounded edit and investigate unseen input.
2. [Tracking and evidence](https://github.com/richhiey/ml-llm-ops/blob/main/notebooks/02-tracking-and-evidence.ipynb): declare five configurations, inspect raw and plotted validation metrics, configure logging and audit a new comparison.
3. [Registry and reproduction](https://github.com/richhiey/ml-llm-ops/blob/main/notebooks/03-registry-and-reproduction.ipynb): trace actual artifact identity, promote your selected run and investigate rollback.
4. [Cumulative handoff](https://github.com/richhiey/ml-llm-ops/blob/main/notebooks/04-cumulative-handoff.ipynb): diagnose identity gaps, write a runbook and verify fresh receiving evidence.

The [Campus journey](https://github.com/richhiey/ml-llm-ops/blob/main/docs/course/README.md) and [exact outcome map](https://github.com/richhiey/ml-llm-ops/blob/main/docs/course/outcomes.md) identify each notebook section by Campus activity ID. Keep the same clone and work/project.json between sprints. Setup reopens saved decisions; it does not reset the selected configuration.

Cells tagged student-work are independent attempts. Complete a decision before running a later cell that consumes it. Collapsed feedback comes after the attempt. Guided demonstrations alone do not complete the task. There is nothing to submit.

Figures are produced from actual local records by linden_mlops.visuals and exported under work/figures as SVG and PNG. Campus images are verified reference executions; your own matrix or execution identities can differ. No hosted runtime is used.
